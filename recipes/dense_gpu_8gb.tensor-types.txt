# ── 밀집 4~9B, GPU 전부 상주 (베이스 ftype: IQ4_XS 또는 Q4_K_M) ─────────────────
# 첫 2개 / 마지막 2개 레이어는 양자화 민감도가 가장 큼 (일반적 관찰) → 전체 6비트
blk\.(0|1)\.(attn|ffn)_.*=q6_k
# ↓ 마지막 레이어 번호는 모델에 맞게 수정 (예: 32층이면 30|31, 42층이면 40|41)
blk\.(30|31)\.(attn|ffn)_.*=q6_k
# V 투영과 FFN down 은 출력 분포에 직접 영향 → 5~6비트
attn_v=q6_k
ffn_down=q5_k
# K 는 RoPE 로 위치정보를 실어 장문맥에서 민감 → 5비트
attn_k=q5_k
# Q, O, gate, up 은 베이스 타입(IQ4_XS/Q4_K) 그대로 — 여기선 명시하지 않음
